# Gestion Contact

Application Android (Java) de gestion de contacts, réalisée dans le cadre de mes études.

## Fonctionnalités

- Écran de connexion avec un identifiant de démonstration, défini dans `MainActivity.java`
- Ajout d'un contact : nom, prénom et numéro
- Affichage des contacts dans une liste personnalisée
- Appel d'un contact depuis la liste
- Suppression d'un contact, avec confirmation

## Limites actuelles

- Les contacts restent en mémoire et sont perdus à la fermeture de l'application.
- La recherche et la modification d'un contact ne sont pas terminées.

## Technologies

- Java, Android SDK (minSdk 21, targetSdk 32)
- AndroidX AppCompat, Material Components, ConstraintLayout

## Lancer le projet

1. Ouvre le projet dans Android Studio.
2. Lance l'application sur un téléphone ou un émulateur.
